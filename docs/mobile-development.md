# 모바일 개발 안내

## 실행

Node.js 22.13 이상(검증 기준 24), pnpm 11.25.0을 사용한다.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

기본 화면은 Expo 개발 서버의 QR로 지원되는 Expo Go에서 열 수 있다. **네이티브 음성 인식은 Expo Go에 포함되지 않으므로 개발 빌드가 필요하다.** Android Studio·Xcode가 설치된 환경에서 `pnpm --filter @seolin/mobile android` / `ios`로 네이티브 앱을 빌드한다. Expo Go와 프로젝트 SDK 호환성을 확인한다. 배포용 설치 파일 생성에는 별도 Android/iOS 빌드 환경 또는 EAS 설정이 필요하다.

```sh
pnpm web        # 개발 검증용 브라우저 화면 (최종 PC 서비스 아님)
pnpm check      # TypeScript와 등록된 테스트
pnpm export     # Android/iOS/Web JavaScript 번들 생성
```

`export`는 APK/IPA 생성이나 스토어 출시 검증이 아니다. 기기 권한, 회전, 음향, 백그라운드 복귀, TV 미러링은 실제 Android·iPhone에서 따로 확인한다.

## 경계

- `apps/mobile`: Expo Router 기반 플랫폼 화면 및 네이티브 기기 연결
- `packages/contracts`: 미니앱 목록·상태·향후 서버 권한 응답의 데이터 계약
- `packages/design-tokens`: 서린 브랜드색과 공통 시각 기준
- O/X는 네이티브 화면으로 재구성했다. 나머지 다섯 게임은 원본 엔진을 앱에 번들로 포함하고 공통 WebView 실행기에서 연다. [원본 기능·기기 연결·저장 범위](live-games.md)를 참고한다.
- `com.seolin.kit.dev`는 개발용 식별자다. 스토어 계정과 최종 번들 ID, 서명·도메인은 아직 연결하지 않았다.
- 서버·회원·결제·실시간 인기 집계는 이 단계에서 운영하지 않는다. 앱에 비밀키를 넣지 않는다.

## 의존성 기준

Expo 57의 안정 버전과 해당 SDK에 맞는 React Native 조합을 사용한다. Expo의 `bundledNativeModules.json`과 `expo install --check`로 호환 범위를 확인한다.

- [Expo SDK 기준](https://docs.expo.dev/versions/latest/)
- [Expo monorepo 설정](https://docs.expo.dev/guides/monorepos/)

## 플랫폼 화면 검증

- 홈 / 미니앱 / 내 앱 / 마이 및 미니앱 상세 화면을 제공한다.
- 목록 이름·아이콘은 상세, `시작`은 해당 게임의 준비 화면으로 이동한다.
- 홈의 오늘의 게임은 카탈로그에 연결한다. 현재 O/X이며, 비공개·제거 시 사용 가능한 앱으로 대체하고 목록이 비면 카드를 숨긴다.
- 큰 이미지 카테고리 버튼은 미니앱의 해당 필터로 연결한다. 진입 타이포는 동작 줄이기 설정을 따른다.
- 보관함은 저장 성공 후에만 화면에 반영하고, 로딩·오류 시 덮어쓰지 않는다.
- 검색·카테고리 조합과 손상된 보관함 데이터는 단위 테스트로 검증한다.
- 2026-10-14 브라우저 390×844에서 상세 표시와 보관함 추가 후 재접속 유지를 확인했다. 2026-10-15 홈·카메라·다섯 게임 개편의 브라우저 UI 검증은 도구 보안 정책으로 미수행이다. 실제 기기 뒤로가기·접근성도 별도 확인한다.
- 여섯 게임 모두 준비·진행 경로를 제공한다. 현재 개발 버전은 무료이며 회원·구독 권한은 아직 연결하지 않았다.


## O/X 구현과 저장

`miniapps/ox`는 React Native에 종속되지 않은 문제 검증·입력 파서·진행 상태 로직이다. 화면과 기기 연결은 `apps/mobile/app/ox`, 로컬 저장은 `src/state/lesson.tsx`에 둔다. 수업 한 세트(최대 100문제, 문제당 200자)를 저장하며 여러 세트 관리·공유·클라우드 동기화는 후속 범위다. 기기 데이터 삭제 시 복구되지 않으므로 운영용 원본은 별도로 보관한다.

문제 붙여넣기는 한 줄에 `문제 | O` 또는 `문제 | X` 형식이다. 잘못된 줄이 있으면 전체 입력을 거절하고 문제 번호를 안내한다. 삭제 직후 복원은 다른 문제의 편집을 유지한다. 수업 설정은 게임 화면을 열 때 저장하고, 편집 내용은 저장 버튼을 눌러 반영한다.

타이머는 경과 시간 기준으로 계산한다. 수동 모드는 시간 종료 후 정답을 숨긴 채 기다린다. 자동 모드는 정답을 3초 보여준 뒤 다음 문제를 시작한다. 백그라운드 전환·수업 화면 이탈 시 일시정지하고 복귀 시 직접 이어서 진행한다. 종료 시 시간·진행 순서를 초기화하지만 저장한 문제는 유지한다.

가로 고정과 화면 꺼짐 방지 요청은 수업 화면을 떠날 때 해제한다. iPad 가로 고정을 위해 현재 전체 화면 모드를 사용한다. 실제 TV 미러링은 OS에서 연결하며 조작 버튼도 동일하게 송출된다. 실시간 카메라는 진행 화면에서 선택적으로 켠다. 전후면 전환과 좌우 반전을 제공하며 영상은 녹화·저장·전송하지 않는다. 카메라 권한 거부·연결 실패 시 안내를 표시하고 게임은 그대로 진행한다. 카메라는 화면 이탈·수업 완료 시 해제하며 백그라운드 전환 후에는 사용자가 다시 켠다. 마이크 권한은 요청하지 않는다. 음성 시작·별도 TV 제어 화면은 아직 포함하지 않았다.

`countdown.wav`는 이 프로젝트에서 생성한 880Hz 짧은 안내음이다. 마지막 3초에 사용한다. 원본 HTML의 외부 음원은 복사하지 않았다.

이 Mac에서 개발 서버의 파일 감시 제한이 발생하면 Watchman을 준비하거나 `CI=1 pnpm web`로 감시 없이 실행한다. 감시 없이 실행 중인 서버는 코드 변경 후 재시작해야 한다.
