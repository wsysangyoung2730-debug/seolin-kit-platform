# 격파 한 판

`taekwondo-breaking`은 기존 카메라 게임 `breaking`과 별도인 3D 랜덤 뽑기 미니앱이다. 목록·상세·보관함에서 `/board-break`로 실행한다. 독립 미리보기는 `pnpm breaking:dev`로 실행하며 기본 주소는 http://127.0.0.1:4174/ 이다.

## 게임 흐름

세 장의 송판 중 하나를 화면 또는 번호 버튼으로 고른 다음 ‘기합 넣고 격파!’를 누른다. 제공한 `front_kick_02` 동작의 타격 시점에 송판을 좌우 파편과 작은 조각으로 바꾸고 결과를 공개한다. 당첨이면 금빛 메달·팻말과 `clap` 애니메이션을 재생한다. ‘한 번 더!’는 새 결과 배치와 온전한 송판을 준비한다.

매 판 3장의 송판에 설정한 개수의 당첨을 Fisher–Yates 방식으로 섞는다. `crypto.getRandomValues`와 rejection sampling을 사용하며 선택 이후 결과를 바꾸지 않는다. 설정은 당첨 송판 0~3장, 선물 이름, 소리를 제공한다. 진행 중에는 재실행과 설정 변경을 막는다. 결과는 타격 순간 한 번만 저장하며 최근 50건을 유지한다. 별도 저장 키 `seolin-board-break-v1`을 사용한다.

## 에셋과 연출

제공받은 GLB 12개의 내부 텍스처를 최대 1024px로 줄였다. 메시·스켈레톤·애니메이션 데이터는 그대로 유지했다. 총 약 142MB에서 5.9MB로 감소했다. 원본 파일명·SHA256·삼각형 수·애니메이션 이름은 `miniapps/board-break/assets/models.json`에 기록했다. 정적 캐릭터 원본도 함께 보존하며 게임 주인공에는 애니메이션용 스켈레톤을 사용한다.

새 배경은 짙은 남색 벽 하단과 밝은 목재 바닥으로 공간을 구분했다. 그 위에 실제 3D 목재 무대와 그림자를 배치한다. ‘격파 한 판’ 로고는 송판·금빛 별·남색 띠를 조합한 투명 PNG다. 생성은 내장 image_gen을 사용했으며 프롬프트는 `board-break-art-prompts.txt`에 보존했다.

## 앱 연결

`pnpm miniapps:build`는 핀볼과 격파를 함께 빌드한다. 웹은 로컬 자산을 iframe에서 읽으며 네이티브는 에셋을 포함한 오프라인 HTML을 WebView에서 실행한다. 네이티브 기록은 검증된 메시지를 통해 AsyncStorage에 저장한다. 화면 이탈 시 일시정지하며 종료 시 애니메이션·오디오·WebGL 자원을 해제한다. Android/iOS 실기기 동작은 별도 현장 확인이 필요하다.
