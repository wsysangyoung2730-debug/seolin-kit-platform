# 수업 타이머

수업 도구 카테고리의 `수업 타이머`에서 시간과 반복 흐름을 준비한다. 앱 상세 화면, 목록의 시작 버튼, 보관함에서 같은 준비 화면으로 접근한다.

## 준비와 진행

- 수업 시간은 1초~59분 59초로 설정한다. 1·3·5·10분 빠른 선택을 제공한다.
- 처음 준비 시간은 0~60초, 반복은 1~30회, 회차 사이 휴식은 0~600초다. 전체 시간은 24시간 이하다.
- 준비 시간은 맨 처음 한 번만 적용한다. 휴식이 0초면 생략하고 마지막 수업 뒤에는 휴식을 붙이지 않는다.
- `타이머 준비하기`는 큰 숫자 화면을 연다. `시작하기`를 눌러야 시간이 흐른다.
- 일시정지·이어서 진행·처음부터·마치기를 제공한다. 진행 중 초기화나 종료는 확인을 거친다. 확인을 취소해도 자동 재개하지 않는다.
- 총시간, 전체 남은 시간, 현재 회차, 현재 및 다음 구간을 표시한다. 휴식·준비·수업은 글자와 색을 함께 사용한다.
- 화면 회전을 강제하지 않는다. 기기의 세로·가로 크기에 따라 숫자와 여백을 조정하며 작은 화면에서는 스크롤로 모든 조작에 접근한다.
- TV에는 기기 화면 미러링으로 표시한다. 조작 버튼도 함께 표시된다.

## 시간 및 수명 주기

`src/tools/timer-engine.ts`는 외부에서 전달한 단조 증가 시각(`performance.now()`)과 누적 진행 시간으로 계산한다. 100ms interval은 화면 갱신 요청일 뿐 초를 차감하는 기준이 아니다. 갱신이 늦어져 여러 구간을 넘겨도 현재 구간과 종료 시점을 계산한다.

종료 시각을 먼저 확인한 뒤 일시정지를 적용한다. 종료 시각에서 일시정지를 눌러도 완료 상태를 되살리지 않는다. 완료 상태의 추가 tick·resume은 같은 상태를 반환한다.

앱이 백그라운드로 가거나 다른 화면으로 이동하면 일시정지한다. Android 알림창 등 AppState blur도 같은 방식으로 처리한다. 돌아오면 사용자가 직접 이어서 진행해야 한다. 화면이 활성 상태일 때만 화면 꺼짐 방지를 요청하고, 늦게 완료된 요청도 해당 요청의 태그로 해제한다.

효과음은 기존 `countdown.wav`를 사용한다. 구간 시작, 마지막 3초, 완료를 알리며 지연된 tick에서 지나간 소리를 한꺼번에 재생하지 않는다. 일시정지·종료·화면 이탈 시 소리를 중단하고, 비동기 seek 완료 후에도 현재 화면이 활성 상태인지 확인한다. 재생 실패는 화면에 안내하고 무음 진행을 허용한다.

`TimerSession`은 수업 타이머와 타바타가 공유할 수 있도록 `title`, `plan`, `sound`, `onExit`을 받는다. `TimerStep`에는 `label`, `seconds`, `round`, `totalRounds`, `kind`(`prepare`/`work`/`rest`)가 들어간다. 0초 구간은 plan에 넣지 않는다.

## 설정 저장

`seolin.classroom-timer.settings.v1`에 기기별 설정을 저장한다. 저장값을 먼저 검증하며, 아직 불러오지 않았거나 불러오기에 실패한 상태에서 기본값으로 덮어쓰지 않는다.

- 읽기 실패: 다시 불러오기 또는 기본 설정으로 저장 없이 진행.
- 쓰기 실패: 현재 입력을 유지하고 저장 재시도 또는 이번에는 저장 없이 준비.
- 저장 없이 진행: 기존 저장 내용은 건드리지 않으며 이번 화면에서만 설정을 유지.
- 자동 저장은 하지 않는다. 준비 버튼을 눌렀을 때 검증 후 저장한다.

공유 hook `useTimerPreferences`는 비동기 로드 요청을 구분하고, 화면이 사라진 뒤 결과로 화면을 갱신하지 않는다. 저장 완료 전에 이탈해도 타이머가 뒤늦게 실행되지 않는다.

## 검증

자동 테스트로 지연 tick에 따른 구간 건너뛰기, 일시정지 중 시간 유지, 소수 초 보존, 종료 시각의 일시정지, 중복 완료 방지, 0초 준비·휴식 생략, 마지막 휴식 생략, 입력 범위 및 비정수 거부, 저장값 검증을 확인한다.

아래 항목은 실제 기기에서 별도로 확인한다. 이 문서는 절차이며 현장 검증 완료를 뜻하지 않는다.

- [ ] Android / iOS에서 짧은 반복 수업의 준비 → 수업 → 휴식 → 완료 확인
- [ ] 실행 중 홈으로 이동·화면 잠금·알림창 열기 후 수동 재개 확인
- [ ] 뒤로 가기·종료·초기화 확인 창에서 취소 시 일시정지 유지 확인
- [ ] 가로·세로 및 태블릿·TV 미러링에서 숫자/조작 버튼 가독성 확인
- [ ] 기기 음량·무음 설정·이어폰/TV 오디오 출력에서 효과음 확인
- [ ] 저장 읽기/쓰기 실패 상황에서 재시도·저장 없이 진행 확인
