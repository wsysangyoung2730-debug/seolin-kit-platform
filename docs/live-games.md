# 원본 미니앱 통합

## 구현 방식

O/X는 네이티브 화면이다. 나머지 다섯 게임은 사용자가 제공한 `TalkFile_LIVE GAME by SEOLIN.html.html`의 GAMES 객체에서 추출한 엔진을 앱에 번들로 포함한다. 별도 사이트에서 코드를 내려받지 않는다. 원본의 동작 감지·단어 판정·카드 게임·음원을 먼저 보존하고, 앱의 상세·준비 화면과 브랜드 색·모바일 배치를 적용한다.

`miniapps/live-games/sources`의 HTML은 수정하지 않는다. `shared`에서 공통 점수판, 모바일 테마와 기기 연결을 관리한다. `node scripts/sync-live-games.mjs`로 Metro가 읽는 문자열 모듈과 SHA-256 목록을 만든다. 게임별 등록은 `src/components/live/games.ts`와 카탈로그에 추가한다. 원본 HTML·내장 사전·음원에 포함된 출처 표시는 그대로 보존한다.

원본 기능의 코드 보존은 실제 기기 동작 검증과 다르다. 아래 실기기 항목을 통과하기 전에는 출시 검증 완료로 간주하지 않는다.

## 기기 연결과 저장

- React Native WebView 안에서 로컬 HTML을 실행한다. 브라우저 미리보기는 같은 번들 HTML을 iframe으로 실행한다.
- 카메라·음성 인식은 준비 화면에서 선택한다. 움직임 감지에는 카메라가 필요하다. 영상은 녹화·업로드하지 않는다.
- 네이티브 음성 인식은 `expo-speech-recognition`으로 기존 Web Speech 이벤트에 연결한다. Expo Go가 아닌 해당 모듈을 포함한 개발 빌드가 필요하다. 음성은 OS 음성 서비스가 처리하므로 서비스 설정에 따라 인터넷을 사용할 수 있다. 서린 서버로 음성·영상을 전송하지 않는다.
- 음성을 끈 경우 버튼과 직접 입력을 유지한다. 원본의 읽어주기는 네이티브 TTS로 연결한다.
- 네이티브 사진 선택은 시스템 파일 선택기로 연결한다. 모바일에서는 폴더 선택 버튼도 여러 사진 선택으로 제공한다. 한 번에 50MB까지 선택하며 초과 시 다시 선택하도록 안내한다. 사진은 현재 게임에서만 사용하고 보관함에 저장하지 않는다.
- 팀 점수·원본이 저장하는 설정·기록은 하나의 로컬 저장소에 직렬 저장해 게임끼리 공유한다. 읽기에 실패하면 기존 데이터를 덮어쓰지 않는다.
- 화면 종료·백그라운드에서는 게임 뷰를 닫고 카메라·음성을 해제한다. 진행 중 라운드와 선택한 사진은 초기화되며 준비 화면에서 이를 안내한다. 시스템 사진 선택 중에는 게임 뷰를 유지한다.
- 원본의 선택적 외부 웹폰트 요청은 제거한다. CSP로 원격 스크립트·네트워크 요청을 막고 외부 페이지 이동은 허용하지 않는다. 저장·음성·파일 브리지 메시지는 형식·크기·허용 키를 검증한다.

## 검증

- 자동: 원본 SHA-256, 조립된 모든 인라인 JavaScript 구문, 저장 형식·메시지 검증, 카메라 늦은 권한 응답 해제, 음성 이벤트의 확정 결과·재시작, 공유 점수 직렬화.
- 실제 Android/iOS: 카메라 허용/거부, 두 카메라 전환·반전·프레임 감지, 한국어 음성 명령/부분·확정 결과, 음성 재시작, 파일 선택 취소/여러 사진/50MB 초과, 백그라운드와 반복 종료, TV 미러링.
- 모바일 조작: 모든 설정에 접근 가능한지, 숫자 입력과 소프트 키보드, 전체 화면 복귀, 점수판 드래그·접기·크기 조절, 게임 전체 종료까지 확인한다.

브라우저 도구가 현재 localhost 화면 접근을 보안 정책으로 차단하여 이번 통합의 UI 자동 조작은 미수행이다. 현장 검증은 각 게임의 이슈에 미완료로 남긴다.
