# 타바타 타이머

수업 도구의 독립 미니앱이다. 운동과 휴식을 반복하고 준비·운동·휴식 상태와 남은 시간, 현재 세트를 큰 화면으로 표시한다. 계정이나 네트워크 연결 없이 설정할 수 있다.

## 기본값과 진행 순서

- 기본: 준비 10초 → 운동 20초 / 휴식 10초 × 8세트.
- 준비 시간은 처음에 한 번만 진행한다.
- 마지막 세트의 운동 직후 완료하며 마지막 휴식은 진행하지 않는다.
- 기본 총 진행 시간은 **4분**이다. 준비 10초, 운동 합계 160초, 세트 사이 휴식 합계 70초다.
- 빠른 설정은 `20초 / 10초 × 8세트`, `30초 / 15초 × 6세트`이며 준비 시간은 두 설정 모두 10초다. 소리 안내 선택은 유지한다.
- 준비 또는 휴식이 0초이면 해당 단계를 생략한다. 1세트에서는 휴식 시간을 입력했더라도 휴식하지 않는다.

## 입력과 실행

| 항목         | 범위        |
| ------------ | ----------- |
| 준비         | 0~60초      |
| 운동         | 1~3,600초   |
| 휴식         | 0~3,600초   |
| 반복         | 1~99세트    |
| 총 진행 시간 | 12시간 이내 |

모든 숫자는 정수여야 한다. 빈 입력, 소수, 지수 표기, 음수, 무한값을 허용하지 않는다. 유효한 설정에 대해서만 총 진행 시간, 운동 합계와 진행 순서를 표시하고 저장·실행한다.

`저장하고 타바타 시작`으로 진행 화면을 열고 진행 화면에서 시작한다. `설정만 저장`으로 실행하지 않고 현재 설정을 보관할 수 있다. 공용 `TimerSession`이 시작·일시정지·재개·초기화, 화면 이탈 시 일시정지와 뒤로가기 처리를 맡는다. 타바타 설정 화면으로 돌아오면 편집한 값이 유지된다. 진행 상태 자체는 앱 종료 후 복원하지 않는다.

## 저장과 오류 복구

설정은 AsyncStorage의 `seolin.tools.tabata.v1`에 `{ version: 1, settings }` 형태로 저장한다. 입력 변경이나 프리셋 선택만으로 저장하지 않는다.

- 처음 실행하여 저장값이 없으면 기본값으로 시작한다.
- 손상된 값, 지원하지 않는 버전, 읽기 오류는 기본값으로 자동 덮어쓰지 않는다.
- 읽기 실패 시 `다시 불러오기`, `저장 없이 사용`, `기본 설정으로 다시 저장` 중 선택할 수 있다. 마지막 버튼은 기존 설정을 명시적으로 기본값으로 교체한다.
- `저장 없이 사용`은 이번 화면에서만 기본값을 바탕으로 설정·실행한다. 기존 저장값은 유지하며 저장 버튼은 숨긴다.
- 저장 실패 시 오류를 표시하고 저장을 다시 시도하거나 `이번에는 저장 없이 시작`을 선택할 수 있다.
- 화면이 닫히거나 새로운 읽기가 시작되면 이전 비동기 결과를 화면에 적용하지 않는다.
