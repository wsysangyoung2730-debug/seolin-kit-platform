## 실제 기기에서 남은 검사

위 검사는 모바일 네이티브 설치와 현장 검증을 대신하지 않는다.

- [ ] Android / iPhone / 태블릿 실행 및 탐색·뒤로가기·글자 크기·접근성
- [ ] 가로 진입 / 종료 후 방향 복원, iPad 전체 화면
- [ ] 효과음 켜기·끄기, 무음 모드, Bluetooth·TV 음향
- [ ] 카운트 / 자동 정답 표시 중 백그라운드·잠금 → 복귀 시 일시정지 유지
- [ ] 게임을 반복 진입·종료해 타이머·화면 꺼짐 방지 해제 확인
- [ ] TV 미러링에서 먼 거리 문제 가독성과 조작 동선 확인
- [ ] APK/IPA 빌드, 정식 아이콘·스토어 식별자·서명 확정

## 이번 버전의 범위

O/X 1종만 실행 가능하다. 학생별 응답 수집·채점, 여러 문제 세트, 카메라·음성 인식, 로그인·결제·리뷰 작성·순위 집계·도장 로고 변경은 제공하지 않는다. 현재 수업 한 세트와 내 앱 목록은 기기에 저장하며, 복원 불가능한 데이터는 자동으로 덮어쓰지 않는다.
