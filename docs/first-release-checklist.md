## 실제 기기에서 남은 검사

위 검사는 모바일 네이티브 설치와 현장 검증을 대신하지 않는다.

- [ ] Android / iPhone / 태블릿 실행 및 탐색·뒤로가기·글자 크기·접근성
- [ ] 가로 진입 / 종료 후 방향 복원, iPad 전체 화면
- [ ] 효과음 켜기·끄기, 무음 모드, Bluetooth·TV 음향
- [ ] 카운트 / 자동 정답 표시 중 백그라운드·잠금 → 복귀 시 일시정지 유지
- [ ] 게임을 반복 진입·종료해 타이머·화면 꺼짐 방지 해제 확인
- [ ] TV 미러링에서 먼 거리 문제 가독성과 조작 동선 확인
- [ ] APK/IPA 빌드, 정식 아이콘·스토어 식별자·서명 확정

## 이번 버전의 범위

O/X와 원본 HTML 기반 다섯 게임을 실행하도록 연결했다. 학생별 응답 수집·채점, 여러 O/X 문제 세트, 로그인·결제·리뷰 작성·순위 집계·도장 로고 변경은 제공하지 않는다. O/X 수업 한 세트, 내 앱 목록, 원본 게임이 저장하는 설정·팀 점수는 기기에 저장한다. 복원 불가능한 데이터는 자동으로 덮어쓰지 않는다. 음성 인식·사진 선택은 구현되어 있으나 네이티브 실기기 확인은 남아 있다.

## O/X 카메라 무대 개편 (2026-10-15)

- [x] TypeScript·기존 도메인 테스트 10개 및 3개 플랫폼 번들 생성
- [x] 선택형 카메라와 전후면·좌우 반전, 권한 거부 안내 구현
- [x] 종료·백그라운드 해제와 웹의 늦은 권한 응답 시 스트림 정리 코드 확인
- [ ] 개편 화면 브라우저 조작·가로/세로 육안 검증 (브라우저 도구 보안 정책 차단)
- [ ] Android/iOS 권한 허용·거부·설정 변경 후 재시도
- [ ] 전후면·좌우 반전, 촬영 표시등의 종료·백그라운드 해제 확인
- [ ] 카메라 없는 기기, 다른 앱 사용 중 오류에도 수업 지속 확인
- [ ] TV 미러링에서 실시간 영상·문제·O/X 가독성 및 수업 흐름 확인

실제 기기에서 카메라를 켠 뒤 전후면과 좌우 반전을 각각 조작한다. 수업 중 홈 화면으로 나가 촬영 표시등이 꺼지는지 확인하고, 복귀 시 수업 일시정지 및 카메라 꺼짐을 확인한다. 권한을 거부한 상태에서도 전체 문제를 완료해 본다.
