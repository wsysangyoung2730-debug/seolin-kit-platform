# 팀 나누기 & 랜덤 뽑기

수업 도구 카테고리의 미니앱이며 `/tools/teams`에서 실행한다. 하나의 명단을 **팀 나누기 / 랜덤 뽑기** 두 탭에서 사용한다.

## 참여 명단

- 이름을 한 줄에 한 명씩 입력한다. 빈 줄은 무시하며 최대 100명, 이름당 30자까지 허용한다.
- 이름이 같아도 별개 참여자로 보존한다. 같은 이름에는 입력 순서의 번호를 붙여 `민수 · 1번`, `민수 · 3번`처럼 표시한다. 실제 같은 학생을 중복 입력했는지 확인하라는 안내를 제공한다.
- 너무 긴 이름, 초과 인원, 제어 문자, 범위를 벗어난 숫자는 오류를 표시한다. 입력을 자르거나 지정한 인원을 임의로 바꾸지 않는다.
- 명단을 한 글자라도 수정하면 기존 팀과 추첨 기록을 즉시 초기화한다. 이전 참여자의 결과를 새 명단에 재사용하지 않는다.

## 팀 나누기

- 2명 이상일 때 2~20개 팀으로 나눈다. 팀 수가 참여 인원보다 많을 수 없다.
- Fisher–Yates 방식으로 순서를 섞은 뒤 순환 배정한다. 각 참여자는 정확히 한 팀에 들어가며 팀별 인원 차이는 최대 1명이다.
- 팀 수를 수정하면 기존 팀 결과를 지운다. 다시 나누기 버튼으로 새로운 편성을 만들 수 있다.
- 결과는 큰 이름 카드로 보여주며, 생성 직후 결과 위치로 이동한다. 별도의 전송 기능 없이 기기 화면 미러링으로 보여줄 수 있다.

## 랜덤 뽑기

- 한 번에 1명부터 현재 남은 인원까지 뽑는다. 한 회차 안에서는 같은 참여자를 중복 선택하지 않는다.
- **이미 뽑힌 사람 제외**가 기본으로 켜져 있다. 모든 이전 추첨 기록의 참여자를 제외하고, 모두 뽑힌 경우 초기화를 안내한다.
- 제외 기능을 끄면 이전 회차에 뽑힌 사람도 다시 뽑힐 수 있다. 다시 켜면 기능이 꺼져 있을 때의 기록까지 포함해 제외한다.
- 팀 편성 결과는 추첨 대상을 제한하지 않는다. 추첨은 참여 명단 전체를 대상으로 한다.
- 최근 결과와 회차별 기록을 제공한다. 기본은 최근 5회, 전체 기록 보기로 최대 100회까지 확인한다. 100회를 채우면 초기화를 안내한다.
- **추첨 기록 초기화**는 모든 참여자를 다시 추첨 가능 상태로 되돌린다. 현재 입력한 명단과 팀 편성은 유지한다.

## 기기 저장

- `이 기기에 명단 저장`을 누를 때만 AsyncStorage에 명단을 저장한다. 저장 키는 `seolin.tools.teams.roster.v1`이다.
- 이름 목록과 스키마 버전만 저장한다. 팀 결과와 추첨 기록은 저장하지 않으며 서버로 명단을 전송하지 않는다.
- 다음 진입 시 저장된 명단을 검증해 복원한다. 불러오는 동안 입력과 실행을 잠가 늦은 복원이 사용자의 입력을 덮어쓰지 않게 한다.
- 잘못된 저장 형식 또는 읽기 실패를 표시하며 기존 데이터에 자동으로 쓰지 않는다. 다시 불러오기, 현재 명단으로 명시적 새 저장, 저장 명단 삭제 중 선택할 수 있다.
- 쓰기 실패가 나도 현재 입력으로 계속 사용할 수 있다. 저장 명단 삭제는 기기 저장본만 삭제하며 현재 화면의 입력을 유지한다.
- 화면을 닫으면 저장하지 않은 명단과 결과는 유지되지 않는다. 앱을 백그라운드로 보냈다가 돌아오는 것은 화면을 닫는 것과 다르다.
