# 띠 핀볼

기존 태권뽑기와 별도로 실행하는 3D 미니앱. 카탈로그 ID는 `taekwondo-pinball`, 실행 경로는 `/pinball`이다.

## 실행

```sh
pnpm install --frozen-lockfile
pnpm pinball:dev # 단독 미니앱: http://127.0.0.1:4173
pnpm web         # 플랫폼에서 실행
pnpm check
pnpm export      # Web / Android / iOS JS 번들 생성
```

루트의 개발·타입 검사·내보내기 명령은 미니앱을 먼저 빌드한다. 직접 `@seolin/mobile` 명령을 실행한다면 먼저 `pnpm pinball:build`를 실행해야 한다.

## 동작

- 출발 위치를 조절해 한 번에 하나의 공을 떨어뜨린다.
- 물리 엔진이 핀·미트·쿠션·송판·띠 경사로의 충돌을 계산한다. 미리 당첨 결과를 고른 뒤 공을 이동시키지 않는다.
- 공이 도착한 다섯 칸 중 하나로 결과를 결정한다. 당첨 칸 수(0~5)와 선물 이름을 바꿀 수 있다. 칸 수는 보장된 당첨 확률이 아니다.
- 설정은 다음 추첨부터 적용하며 진행 중에는 설정·초기화·추가 추첨을 막는다.
- 최근 50번의 결과와 당시 선물 이름을 기기에 보관한다. 웹은 localStorage, 네이티브는 검증된 WebView 메시지를 통해 AsyncStorage에 직렬로 저장한다.
- 잘못된 저장 데이터는 자동으로 덮어쓰지 않는다. 사용자가 기록 초기화를 선택하면 새로 시작한다.
- 페이지가 숨겨지거나 네이티브 앱이 비활성화되면 공 이동을 일시정지한다. 종료·화면 이탈 시 렌더링, 오디오와 물리 연산을 해제한다.
- 소리와 감소된 모션 설정을 지원한다. WebGL/모델 로드 실패와 그래픽 컨텍스트 손실 시 재시작 안내를 표시한다.

## 자산과 빌드

`miniapps/pinball/assets/models/`의 16개 GLB는 사용자가 제공한 원본의 메시를 유지하고 내장 8192px 텍스처를 512~1024px로 줄인 사본이다. 원본 합계 약 216.5MB → 사본 합계 약 3.5MB. `models.json`에 원본 파일명·SHA-256·용량·삼각형 수를 기록했다. 원본 다운로드 파일은 변경하지 않았다.

로고와 도장 배경은 내장 이미지 생성 도구로 새로 만들었다. 생성 프롬프트는 `docs/pinball-art-prompts.txt`에 기록했다.

- Three.js: 모델 로드·조명·재질·그림자·반응형 카메라
- cannon-es: 보드의 로컬 평면에서 공과 단순 충돌체 계산. 미세한 생성 메시 대신 안정적인 충돌 범위를 사용한다.
- `miniapps/pinball/src/state.ts`: 웹·네이티브 공용 저장 검증과 결과 규칙
- `miniapps/pinball/scripts/build.mjs`: 로컬 라이브러리를 묶어 단독 HTML, 웹용 공개 자산, 네이티브용 오프라인 HTML 생성
- `miniapps/pinball/generated/pinball.html`: 약 5.7MB. 16개 모델·로고·배경·스크립트가 포함되어 네이티브 실행 시 외부 CDN이 필요 없다. 이 파일과 웹 공개 자산은 빌드 결과이므로 Git에서 제외한다.
- Expo Metro 설정에 `html`·`glb` 자산 확장자를 등록한다. 네이티브에서는 HTML을 앱에 포함해 Asset/File로 읽고 WebView에 전달한다.

## 검증

- 기존 테스트와 신규 설정·저장·물리 시뮬레이션 테스트 70개 통과
- 20가지 출발 위치·초기 속도 조합에서 정상 결과 도착 및 재실행 확인
- TypeScript 검사 통과
- Web / Android / iOS JS 번들 생성 성공
- 브라우저에서 모델 16종 로드, 중복 실행 방지, 당첨·꽝, 선물 변경, 설정·기록 복원 확인
- 390×844 레이아웃에서 가로 넘침 없음

Android/iOS 실제 기기와 TV 미러링에서의 프레임 속도·오디오·중단 복귀는 추가 현장 검증이 필요하다. JS 번들 생성은 APK/IPA 설치 검증을 의미하지 않는다.
