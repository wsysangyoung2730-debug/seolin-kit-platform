# 임시 모바일 에셋

- `seolin-kit-icon.png`: 서린 정식 로고를 참고한 앱 묶음형 시안. 앱 아이콘·플랫폼 브랜딩용이다.
- `ox-icon.png`: 흰 O와 코랄 X로 구성한 독립 미니앱 아이콘이다.

사용자가 제공한 로고와 승인한 UI 방향을 참고하여 기본 이미지 생성 도구로 별도 제작했다. 생성 지시: 설명 글자를 제거한 정사각형 전체 배경 아이콘, 로고의 안전 여백 확보, 기존 남색·O/X 디자인 유지. 배포용 최종 브랜드 승인은 별도다.

카테고리·탐색용 아이콘은 코드 기반 벡터 컴포넌트로 관리한다. 작은 UI 아이콘마다 큰 비트맵을 추가하지 않는다. 미니앱 아이콘과 플랫폼 로고를 같은 파일로 취급하지 않는다.
